# V0.2 Roadmap: Market Insights Enhancement

## Why V0.2 starts with analytical feature engineering
V0.1 delivered a stable and reproducible dashboard foundation. V0.2 begins by strengthening the analytical data layer so future dashboard insights are consistent, explainable, and easy to iterate.

## V0.2 analytical features added in this first step
- `release_year`
- `owners_low`, `owners_high`, `owners_mid`
- `total_reviews`
- `positive_rate` (with backward-compatible `positive_ratio` alias retained)
- `review_log`
- `has_reviews`
- `is_free`
- `has_discount`
- `platform_count`
- `price_bucket`

These features are implemented with robust parsing for missing, mixed-type, and messy source values.

## How these features support future dashboard pages
- **Market sizing and timing:** `release_year`, owners range features.
- **Reputation and demand signals:** `total_reviews`, `positive_rate`, `review_log`.
- **Monetization analysis:** `is_free`, `has_discount`, `price_bucket`.
- **Platform accessibility:** `platform_count`.

## Planned later V0.2 steps
1. Market Insights page.
2. Genre and category analysis.
3. Pricing analysis.
4. Review and popularity analysis.
5. Lightweight visualization polish.

## Not included in this first V0.2 step
- No machine learning yet.
- No major dashboard redesign yet.
- No heavy visual styling yet.
- No deployment work yet.
