# V0.2.0 — Market Insights Enhancement

## Summary
V0.2.0 formalizes the project's market-insights milestone with stable descriptive analytics, a dedicated Market Insights dashboard page, reproducible report generation, and documentation cleanup for release readiness.

This release does **not** add machine learning, deployment tooling, or new analytical feature families. It consolidates and presents the completed V0.2 scope.

## Major additions
- Analytical feature engineering foundation for market interpretation, including ownership, review, pricing, and platform-derived columns.
- Dedicated Streamlit Market Insights page for filtered KPI views, market structure exploration, review/popularity views, and ranking tables.
- Reproducible Market Insights Markdown report workflow via script generation.
- Full processed-data report artifact regeneration for V0.2.
- README and project-presentation cleanup for clearer onboarding and terminology consistency.

```bash

  --input data/processed/steam_games_cleaned.csv \
  --output reports/steam_market_insights_v0.2.md
```

## Data interpretation notes
- `owners_mid` is an estimated midpoint of owner ranges, not exact sales.
- `positive_rate` is most meaningful for games with reviews.
- Hidden gems are heuristic candidates, not model predictions.
- V0.2 analytics remain descriptive; no causal inference is included.

## Known limitations
- The current pipeline emphasizes descriptive summaries and ranking-style heuristics rather than explanatory or predictive modeling.
- Report and dashboard outputs depend on processed input quality and upstream source completeness.
- Some recent release-year slices may be temporally incomplete depending on data snapshot timing.
- V0.2 does not include machine learning models, causal analysis, or production deployment architecture.
